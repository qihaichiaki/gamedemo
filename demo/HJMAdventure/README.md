- 知识结构:
  1. http服务器和客户端之间的交互
  2. 使用多线程优化游戏性能
  3. 原子操作/互斥锁 线程同步技术

- 需求分析:
  - 目标: 联机打字游戏
  - 客户端渲染画面需要的数据:
    1. 实时坐标
    2. 打字进度
  - 网络通信的数据交互
    1. JSON字符串(将对象进行序列化和反序列化)
    2. 在本项目中可以抽象为一个**游戏进度**，根据游戏进度解析出实时坐标和打字进度(两个玩家的路是一致的)
