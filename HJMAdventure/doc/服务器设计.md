#### 服务器设计

- 数据结构: 
  - 玩家数据:
    - int 表示的游戏进度
    - 玩家状态也通过int来表示, -1 表示未连接, 0 表示连接成功未开始, >=0 游戏进行中
  - 文本数据:
    - 保存在服务器端本地, 服务通过IO读入

- 服务器路由(下面全是post请求)
  - ``/login`` 登录接口, 根据客户端分配玩家id``[1, 2]``(多余的-1表示)
  - ``/query_text`` 传输文本内容
  - ``/update_1`` 1号玩家同步进度(服务器获得1号玩家进度, 给其同步2号玩家进度)
  - ``/update_2`` 2号玩家同步进度
